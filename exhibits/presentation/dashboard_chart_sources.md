# Dashboard visualizations · C-1.0.1

All charts use FULL_PRIMARY_V1. Effective cutoff is July 1, 2026, 00:00 UTC exclusive. Recorded cutoff is the same instant inclusive. HTML dashboards are offline snapshots with local filters. SVG and PNG files are fixed PowerPoint extracts. Hover points in the HTML for exact values, and use the detail tables for all available counts and values. Synthetic outputs demonstrate reporting logic.

## Validation and design decisions

- Verified all 26 released analytical output hashes. Independently rejoined `customer_age`, `acquisition`, `attribution` and `prediction_age`. All 576 populated calendar mart rows matched signup and mature counts. Every fully mature comparison matched both signed contribution totals and fixed forecast totals.
- Checked campaign inequalities, zero-registration CAC nulls and missing-plan pacing nulls across the full mart. Verified the selected week, the pending cohort checkpoint and the HTML filter logic in Node. SVG files rendered to PNG with librsvg.
- The original strategic cards and tables now lead into a cohort trajectory, then a unit-specific channel bar chart and maturity/coverage details. The original operational table now follows spend and plan trends, aligned registrations/CAC and a maturity breakdown. The targeting and exposure stay at the signed-off reporting grains.
- The strategic main view uses maturity/coverage rather than a second product chart. No cohort-filtered product financial breakdown was added. Appendix C retains the labeled whole-ledger product extract. The campaign mart supports the three disjoint maturity categories shown, but it does not separate causes of mature non-activation. Dashboard freshness is the snapshot timestamp. There is no live feed check, dashboard service, drilldown endpoint, or new forecast.
